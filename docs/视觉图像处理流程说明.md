# FAST-LIVO2 视觉图像及视频流处理流程说明

## 概述

FAST-LIVO2 是一个高效、精确的 LiDAR-惯性-视觉融合定位与建图系统。本文档详细介绍了系统中视觉图像和视频流的处理流程。

## 系统架构

FAST-LIVO2 采用直接法（Direct Method）进行视觉处理，与传统的基于特征点的方法不同，它直接利用图像的光度信息进行状态估计和地图构建。

### 核心模块

1. **LIVMapper** - 主要的映射管理器，协调整个系统
2. **VIOManager** - 视觉惯性里程计管理器，处理视觉数据
3. **Frame** - 帧管理类，存储图像和相关信息
4. **VisualPoint** - 视觉地图点类
5. **Feature** - 特征（图像块）管理类

### 第三阶段：从视觉稀疏地图中检索点

#### 3.1 检索与投影 (VIOManager::retrieveFromVisualSparseMap)

**位置**: `src/vio.cpp:352-782`

这是最关键的步骤之一，从全局视觉地图中检索当前帧可见的地图点。

**核心流程**:

1. **深度图生成**:
   - 将 LiDAR 点云投影到图像平面
   - 创建深度图用于深度连续性检查
   ```cpp
   cv::Mat depth_img = cv::Mat::zeros(height, width, CV_32FC1);
   ```

2. **体素遍历**: 
   - 遍历视觉地图中的所有体素 (feat_map)
   - 检查体素是否在当前相机视野内
   - 将体素位置转换到相机坐标系
   ```cpp
   V3D pt_c(new_frame_->w2f(pt_w));
   V2D px = new_frame_->cam_->world2cam(pt_c);
   ```

3. **视野检查**:
   - 检查点是否在图像边界内
   - 考虑法向量和视角约束
   ```cpp
   if (new_frame_->cam_->isInFrame(pc.cast<int>(), border))
   ```

4. **光线投射 (RayCasting)** (可选):
   如果 `raycast_en` 启用:
   - 对每个网格发射采样光线
   - 沿光线搜索潜在的视觉点
   - 从体素地图或平面地图中找到对应点
   ```cpp
   for (const auto &it : rays_with_sample_points[i])
   {
       V3D sample_point_w = new_frame_->f2w(it);
       // 检查采样点是否落在已有体素中
   }
   ```

5. **深度连续性检查**:
   - 检查地图点周围的深度连续性
   - 过滤深度不连续的点（可能是遮挡边界）
   ```cpp
   for (int u = -patch_size_half; u <= patch_size_half; u++)
   {
       float depth = it[width * (v + int(pc[1])) + u + int(pc[0])];
       if (abs(pt_cam[2] - depth) > 0.5)
           depth_continous = true;
   }
   ```

6. **图像块扭曲 (Warp)**:
   - 根据参考帧和当前帧的相对位姿
   - 计算仿射变换矩阵 A_cur_ref
   - 使用法向量信息（如果启用 normal_en）
   ```cpp
   if (normal_en)
   {
       getWarpMatrixAffineHomography(*cam, ref_ftr->px_, pf, norm_vec, 
                                      T_cur_ref, 0, A_cur_ref_zero);
   }
   ```

7. **搜索层级确定**:
   - 根据仿射变换的尺度变化
   - 确定金字塔搜索层级
   ```cpp
   search_level = getBestSearchLevel(A_cur_ref_zero, 2);
   ```

8. **提取扭曲后的图像块**:
   - 从参考帧中提取变换后的图像块
   - 支持多层金字塔
   ```cpp
   for (int pyramid_level = 0; pyramid_level <= patch_pyrimid_level - 1; pyramid_level++)
   {
       warpAffine(A_cur_ref_zero, ref_ftr->img_, ref_ftr->px_, 
                  ref_ftr->level_, search_level, pyramid_level, 
                  patch_size_half, patch_wrap.data());
   }
   ```

9. **光度误差计算**:
   - 比较扭曲后的参考块与当前帧图像块
   - 考虑曝光时间差异
   ```cpp
   float error = 0.0;
   for (int ind = 0; ind < patch_size_total; ind++)
   {
       error += (ref_ftr->inv_expo_time_ * patch_wrap[ind] - 
                 state->inv_expo_time * patch_buffer[ind]) *
                (ref_ftr->inv_expo_time_ * patch_wrap[ind] - 
                 state->inv_expo_time * patch_buffer[ind]);
   }
   ```

10. **NCC 检查** (可选):
    - 计算归一化互相关 (Normalized Cross-Correlation)
    - 过滤低相关性的点
    ```cpp
    if (ncc_en)
    {
        double ncc = calculateNCC(patch_wrap.data(), patch_buffer.data(), 
                                  patch_size_total);
        if (ncc < ncc_thre) continue;
    }
    ```

11. **构建视觉子地图**:
    - 将通过检验的点加入当前帧的视觉子地图
    - 保存相关信息供后续优化使用
    ```cpp
    visual_submap->voxel_points.push_back(pt);
    visual_submap->propa_errors.push_back(error);
    visual_submap->search_levels.push_back(search_level);
    visual_submap->warp_patch.push_back(patch_wrap);
    ```

**关键数据结构**:
- `grid_num`: 网格类型标记（地图点/点云/未知）
- `retrieve_voxel_points`: 检索到的体素点
- `visual_submap`: 当前帧的视觉子地图
- `rays_with_sample_points`: 光线投射采样点

### 第四阶段：雅可比矩阵计算与 EKF 更新

#### 4.1 雅可比矩阵计算 (VIOManager::computeJacobianAndUpdateEKF)

**位置**: `src/vio.cpp:784-802`

**方法选择**:
- **逆向组合法** (Inverse Compositional): 如果 `inverse_composition_en` 为 true
- **前向组合法** (Forward Compositional): 默认方法

#### 4.2 逆向组合法 (VIOManager::updateStateInverse)

**位置**: `src/vio.cpp:1398-1518`

**核心思想**: 在参考帧中预计算雅可比矩阵，减少迭代过程中的计算量

**步骤**:

1. **预计算参考图像块雅可比矩阵** (如果未缓存):
   ```cpp
   if (has_ref_patch_cache == false) 
       precomputeReferencePatches(level);
   ```
   
   在 `precomputeReferencePatches` 中:
   - 计算图像梯度 (du, dv)
   - 计算投影雅可比矩阵 Jdpi
   - 组合得到关于旋转和平移的雅可比矩阵
   ```cpp
   JdR = Jimg * Jdpi * R_ref_w * p_w_hat;
   Jdt = -Jimg * Jdpi * R_ref_w;
   H_sub_inv.block<1, 6>(...) << JdR, Jdt;
   ```

2. **迭代优化**:
   ```cpp
   for (int iteration = 0; iteration < max_iterations; iteration++)
   ```

3. **计算当前图像块残差**:
   - 将地图点投影到当前帧
   - 计算光度误差（像素灰度差）
   - 使用双线性插值提取像素值
   ```cpp
   double res = w_ref_tl * img_ptr[0] + w_ref_tr * img_ptr[scale] + 
                w_ref_bl * img_ptr[scale * width] + 
                w_ref_br * img_ptr[scale * width + scale] - 
                P[patch_size_total * level + x * patch_size + y];
   ```

4. **更新雅可比矩阵**:
   - 从预计算的 H_sub_inv 中获取雅可比
   - 考虑当前状态进行变换
   ```cpp
   MD(1, 3) J_dR = H_sub_inv.block<1, 3>(...);
   MD(1, 3) J_dt = H_sub_inv.block<1, 3>(...);
   JdR = J_dR * Rwi + J_dt * P_wi_hat * Rwi;
   Jdt = J_dt * Rwi;
   ```

5. **EKF 更新**:
   - 构建信息矩阵 H^T * H
   - 结合状态协方差矩阵
   - 计算卡尔曼增益
   - 更新状态估计
   ```cpp
   H_T_H.block<6, 6>(0, 0) = H_sub_T * H_sub;
   MD(DIM_STATE, DIM_STATE) &&K_1 = (H_T_H + (state->cov / img_point_cov).inverse()).inverse();
   auto solution = -K_1.block<DIM_STATE, 6>(0, 0) * HTz + vec - G.block<DIM_STATE, 6>(0, 0) * vec.block<6, 1>(0, 0);
   (*state) += solution;
   ```

6. **收敛检查**:
   - 检查旋转和平移增量是否足够小
   - 检查误差是否下降
   ```cpp
   if ((rot_add.norm() * 57.3f < 0.001f) && (t_add.norm() * 100.0f < 0.001f))
       EKF_end = true;
   ```

#### 4.3 前向组合法 (VIOManager::updateState)

**位置**: `src/vio.cpp:1520-1688`

**核心思想**: 在当前帧中计算雅可比矩阵，更直观但计算量稍大

**主要区别**:

1. **实时计算图像梯度**:
   - 每次迭代都计算当前帧的图像梯度
   ```cpp
   float du = 0.5f * ((w_ref_tl * img_ptr[scale] + ...) - 
                      (w_ref_tl * img_ptr[-scale] + ...));
   float dv = 0.5f * ((w_ref_tl * img_ptr[scale * width] + ...) - 
                      (w_ref_tl * img_ptr[-scale * width] + ...));
   ```

2. **计算投影雅可比**:
   ```cpp
   computeProjectionJacobian(pf, Jdpi);
   ```

3. **组合雅可比矩阵**:
   - 考虑曝光时间变化（如果启用 exposure_estimate_en）
   ```cpp
   Jimg = Jimg * state->inv_expo_time;
   Jdphi = Jimg * Jdpi * p_hat;
   Jdp = -Jimg * Jdpi;
   JdR = Jdphi * Jdphi_dR + Jdp * Jdp_dR;
   Jdt = Jdp * Jdp_dt;
   ```

4. **支持曝光时间估计**:
   ```cpp
   if (exposure_estimate_en)
       H_sub.block<1, 7>(...) << JdR, Jdt, cur_value;
   else
       H_sub.block<1, 6>(...) << JdR, Jdt;
   ```

**并行化支持**:
- 如果定义了 `MP_EN`，使用 OpenMP 并行计算
```cpp
#ifdef MP_EN
    omp_set_num_threads(MP_PROC_NUM);
    #pragma omp parallel for reduction(+:error, n_meas)
#endif
```

3. **Shi-Tomasi 角点检测**:
   - 评估每个候选点的角点质量
   - 使用 Shi-Tomasi 分数选择最佳点

4. **从体素地图添加点**:
   - 也考虑从平面体素地图添加的点

   ```cpp
   VisualPoint *pt_new = new VisualPoint(pt);

                                  new_frame_->T_f_w_, 0);
   ```

6. **设置法向量**:
   - 根据视角调整法向量方向
   - 确保法向量指向相机
   ```cpp
   double cos_theta = dir.dot(norm_vec);
   if (cos_theta < 0)
       pt_new->normal_ = -pt_var.normal;
   else
       pt_new->normal_ = pt_var.normal;
   ```

7. **插入体素地图**:
   - 将新点插入全局视觉地图的体素结构
   ```cpp
   insertPointIntoVoxelMap(pt_new);
   ```

**关键参数**:
- `grid_size`: 网格大小
- `patch_size`: 图像块大小
- `shiTomasiScore`: 角点质量阈值

#### 6.2 参考图像块更新 (VIOManager::updateReferencePatch)

**位置**: `src/vio.cpp:969-1100`

**目的**: 更新地图点的法向量和选择最佳参考图像块

**流程**:

1. **法向量融合**:
   - 将视觉点与 LiDAR 平面地图关联
   - 使用平面法向量更新视觉点法向量
   ```cpp
   auto iter = plane_map.find(position);
   if (iter != plane_map.end())
   {
       VoxelOctoTree *current_octo = iter->second->find_correspond(p_w);
       VoxelPlane &plane = *current_octo->plane_ptr_;
   ```

2. **距离和不确定性检查**:
   - 检查点到平面的距离
   - 考虑平面半径和协方差
   ```cpp
   float dis_to_plane = plane.normal_(0) * p_w(0) + ... + plane.d_;
   double sigma_l = J_nq * plane.plane_var_ * J_nq.transpose();
   if (dis_to_plane_abs < 3 * sqrt(sigma_l))
   ```

3. **法向量平滑更新**:
   - 保持法向量方向一致性
   - 检查法向量变化量
   ```cpp
   if (pt->previous_normal_.dot(plane.normal_) < 0)
       pt->normal_ = -plane.normal_;
   else
       pt->normal_ = plane.normal_;
   ```

4. **收敛判断**:
   - 检查法向量变化是否小于阈值
   - 检查观测数量是否足够
   ```cpp
   if (normal_update < 0.0001 && pt->obs_.size() > 10)
       pt->is_converged_ = true;
   ```

5. **选择最佳参考图像块**:
   - 计算所有观测间的 NCC（归一化互相关）
   - 考虑视角因素
   - 选择评分最高的观测作为参考
   ```cpp
   for (auto it = pt->obs_.begin(), ite = pt->obs_.end(); it != ite; ++it)
   {
       // 计算与其他观测的 NCC
       NCC += fabs(NCC_up / sqrt(NCC_down1 * NCC_down2));
       score = NCC + cos_angle;
       if (score > score_max)
           pt->ref_patch = ref_patch_temp;
   }
   ```

**数学细节**:

- **NCC 计算**:
  ```
  NCC = Σ[(I_ref(x) - μ_ref) * (I_cur(x) - μ_cur)] / 
        sqrt(Σ(I_ref(x) - μ_ref)² * Σ(I_cur(x) - μ_cur)²)
  ```

- **视角评分**:
  ```
  score = NCC + cos(angle_between_view_and_normal)
  ```

## 关键技术细节

### 1. 直接法光度误差

FAST-LIVO2 使用直接法，直接最小化光度误差：

```
E = Σ [I_ref(p_ref) * exp_time_ref^(-1) - I_cur(W(p_ref, ξ)) * exp_time_cur^(-1)]²
```

其中：
- `I_ref`: 参考图像亮度
- `I_cur`: 当前图像亮度
- `W`: 图像扭曲函数
- `ξ`: 相机位姿参数
- `exp_time`: 曝光时间

### 2. 仿射图像扭曲

#### 2.1 基于法向量的单应性扭曲 (Homography Warp)

**位置**: `src/vio.cpp:252-273`

当启用 `normal_en` 时使用：

```cpp
void getWarpMatrixAffineHomography(...)
```

**原理**:
- 利用平面假设
- 构建单应性矩阵 H
- 计算仿射近似

**数学公式**:
```
H = R + (t * n^T) / d
```
其中：
- R: 旋转矩阵
- t: 平移向量
- n: 平面法向量
- d: 平面深度

**仿射矩阵计算**:
```cpp
const V3D f_cur(H_cur_ref * xyz_ref);
const V3D f_du_cur = H_cur_ref * f_du_ref;
const V3D f_dv_cur = H_cur_ref * f_dv_ref;
A_cur_ref.col(0) = (px_du_cur - px_cur) / kHalfPatchSize;
A_cur_ref.col(1) = (px_dv_cur - px_cur) / kHalfPatchSize;
```

### 3. 图像金字塔与多尺度搜索

#### 3.1 搜索层级确定

**位置**: `src/vio.cpp:320-331`

```cpp
int getBestSearchLevel(const Matrix2d &A_cur_ref, const int max_level)
{
    int search_level = 0;
    double D = A_cur_ref.determinant();
    while (D > 3.0 && search_level < max_level)
    {
        search_level += 1;
        D *= 0.25;  // 每层金字塔面积缩小 4 倍
    }
    return search_level;
}
```

**目的**: 
- 根据尺度变化自动选择金字塔层级
- 提高匹配效率和鲁棒性

### 7. 状态向量与 EKF

#### 7.1 状态向量结构

```cpp
class StatesGroup
{
    M3D rot_end;        // 旋转
    V3D pos_end;        // 位置
    V3D vel_end;        // 速度
    V3D bias_g;         // 陀螺仪偏置
    V3D bias_a;         // 加速度计偏置
    V3D gravity;        // 重力向量
    double inv_expo_time;  // 逆曝光时间
    MatrixXd cov;       // 协方差矩阵
};
```

#### 7.2 EKF 更新公式

**卡尔曼增益**:
```
K = P * H^T * (H * P * H^T + R)^(-1)
```

**状态更新**:
```
x = x + K * (z - h(x))
```

**协方差更新**:
```
P = (I - K * H) * P
```

在代码中：
```cpp
MD(DIM_STATE, DIM_STATE) &&K_1 = 
    (H_T_H + (state->cov / img_point_cov).inverse()).inverse();
auto solution = -K_1.block<DIM_STATE, 6>(0, 0) * HTz + vec - 
                G.block<DIM_STATE, 6>(0, 0) * vec.block<6, 1>(0, 0);
(*state) += solution;
```

## 常见问题与解决方案

### 1. 追踪失败

**可能原因**:
- 光照变化剧烈
- 运动模糊
- 特征不足

**解决方案**:
- 启用曝光时间估计
- 降低运动速度
- 调整 `outlier_threshold`

### 2. 地图点过多

**解决方案**:
- 调整 `grid_size` (增大)
- 提高角点阈值
- 限制观测数量

### 3. 计算延迟

**解决方案**:
- 降低图像分辨率 (`scale` < 1.0)
- 减少金字塔层数
- 启用并行计算
- 降低 `patch_size`

### 4. 法向量不稳定

**解决方案**:
- 确保 LiDAR 平面地图质量
- 增加观测数量
- 调整平面不确定性阈值

## 总结

FAST-LIVO2 的视觉处理流程是一个高度集成的直接法视觉里程计系统，其主要特点包括：

1. **直接法**: 不提取传统特征点，直接使用图像灰度信息
2. **紧耦合**: 与 LiDAR 和 IMU 紧密结合
3. **法向量辅助**: 利用 LiDAR 提供的法向量信息增强视觉追踪
4. **光度一致性**: 考虑曝光时间变化，适应光照变化
5. **体素管理**: 高效的 3D 空间索引和地图管理
6. **多尺度**: 金字塔层级加速和提高鲁棒性
7. **EKF 框架**: 与整个系统的状态估计统一在 EKF 框架下

该系统在退化环境（如光照不足、特征缺乏）中表现优异，适合实时机器人定位和 3D 重建应用。
